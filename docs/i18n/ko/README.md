# synstagram-module-cocoapods-specs

Synstagram 모듈 pod을 위한 비공개 CocoaPods spec 저장소이다.

## Specs

| Pod | 최신 버전 | 설명 |
|-----|----------|------|
| APIService | 1.0.6 | API 서비스 모듈(Auth) |
| Dependencies | 1.0.2 | 의존성 주입 프로토콜(Login, AlbumList) |

## 사용법

`Podfile`에 이 spec 저장소를 source로 추가한다.

```ruby
source 'https://github.com/binaryloader/synstagram-module-cocoapods-specs.git'
```

## 관련 저장소

- https://github.com/binaryloader/synstagram-app
- https://github.com/binaryloader/synstagram-module-apiservice
- https://github.com/binaryloader/synstagram-module-dependencies
