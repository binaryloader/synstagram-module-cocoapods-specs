# synstagram-module-cocoapods-specs

Synstagramモジュールpod向けの非公開CocoaPods specリポジトリです。

## Specs

| Pod | 最新バージョン | 説明 |
|-----|---------------|------|
| APIService | 1.0.6 | APIサービスモジュール(Auth) |
| Dependencies | 1.0.2 | 依存性注入プロトコル(Login, AlbumList) |

## 使い方

`Podfile`にこのspecリポジトリをsourceとして追加します。

```ruby
source 'https://github.com/binaryloader/synstagram-module-cocoapods-specs.git'
```
